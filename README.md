# ledger — 备份复制引擎的变更块区间账本

Go 库，跟踪逻辑磁盘（2^48 块，块号从 0 起，区间一律左闭右开）上的脏块区间及其版本，
并根据复制回执精确清除已确认的版本。账本只记录区间与版本，不搬运块字节。

## 接口

```go
l := ledger.New()

v := l.Mark(start, end)        // 标脏 [start,end)，返回本次独有的全局递增版本
tk, rs := l.Capture(start, end) // 唯一票据 + 捕获时刻的脏区间快照（不清除脏状态）
l.Finish(tk, true)             // 成功：仅清除仍为票据所记版本的块；失败：不清除任何块
cur := l.Ranges(start, end)    // 当前脏区间，按块号排序，相邻同版本合并，不跨干净块
```

- `Finish` 首次调用后票据失效，重复调用（无论成败）不改变状态；回执可乱序。
- 成功回执只确认捕获时的版本：捕获后被重写的块保留新版本，捕获时的干净空洞
  之后变脏也不受该票据影响。
- 调用需串行执行；无持久化、不考虑进程崩溃。

## 复杂度

设 m 为当前脏区间数，k 为本次操作涉及的相交区间数与票据区间数之和：

- 每个操作摊还 O((k+1) log(m+2))，绝不扫描整个账本或遍历其他未结束票据。
- 内部结构为按起点排序的区间 treap，单个万亿块区间只占一个节点，不逐块展开。
- 常驻内存只与当前脏区间和未结束票据的区间总数成正比；票据首次 Finish 后即销毁。

## 测试

```sh
go test ./...              # 全部测试
go test -run TestScale -v  # 规模测试：5 万离散区间 + 5 万次单块更新/捕获/回执，
                           # 并以翻倍规模验证局部操作无全账本扫描（耗时比 ≈ 2.1）
```

覆盖：万亿块区间标脏/捕获/中间三块重写后的精确确认（`TestTrillionBlocks`）、
小地址空间逐块参考模型对拍随机交错操作（重叠票据、干净空洞后写、逆序回执、
失败与重复回执，每步比对完整区间）、规模与内存测量。

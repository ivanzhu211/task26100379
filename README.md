# blockledger

备份复制引擎的变更块区间账本（Go 库）。账本只记录脏块区间与版本、
签发捕获票据并确认复制结果，不搬运块字节。

- 逻辑磁盘 2^48 个块，块号从 0 开始，所有范围左闭右开 `[start, end)`。
- 内部用带 `maxEnd` 增强的 treap 存放脏区间，内存与当前脏区间数及
  未结束票据数成正比；单次操作摊还 O((k+1) log(m+2))，k 为本次涉及的
  相交区间与票据区间数，m 为当前脏区间数。不会逐块展开，也不扫描全账本。

## API

```go
l := blockledger.New()

v := l.Mark(start, end)        // 标脏并返回本次独有的全局递增版本
ticket, rs := l.Capture(s, e)  // 唯一票据 + 捕获时刻的脏区间（不可变，不清脏）
l.Finish(ticket, true)         // 成功：只清除仍为票据所记版本的块
l.Finish(ticket, false)        // 失败：不清除任何块；票据同样失效
dirty := l.Ranges(s, e)        // 当前脏区间，按块号排序，同版本相邻合并
```

- `Range{Start, End, Version}` 表示一个脏区间。
- 成功回执只确认捕获时的版本：捕获后被重写的块保留新版本；
  捕获时干净、之后变脏的块不会被该票据清除。
- 票据首次 `Finish` 后即失效，重复调用（无论成败）不改变状态。
- 调用需串行；范围越界（`start > end` 或 `end > 2^48`）会 panic。
